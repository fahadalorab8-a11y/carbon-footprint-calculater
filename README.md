# Carbon Footprint Calculator

A Bootstrap-based student project recreating the supplied reference layout.

## Files
- `index.html` — page structure and form
- `style.css` — layout and styling

## Run locally
Open `index.html` in a web browser. Bootstrap CSS is loaded from jsDelivr, so an internet connection is needed for Bootstrap styling.

## Publish with GitHub Pages
1. Create a **public** repository on GitHub.
2. Upload `index.html`, `style.css`, and this README.
3. Open **Settings → Pages**.
4. Under Build and deployment, select **Deploy from a branch**.
5. Select `main` and `/(root)`, then Save.
6. Wait for the published URL to appear in the Pages section.
